# Phase 2: Syntax Analysis (Parser & AST) & Symbol Table

The Phase 2 Syntax Analyzer parses the token stream generated by Phase 1 against Context-Free Grammar rules for C, builds a strongly-typed Abstract Syntax Tree (AST), and constructs a Detailed Symbol Table.

---

## 1. Components & Modules

- **`parser.py`**: LALR(1) parser core implemented using **PLY (`ply.yacc`)**. Implements grammar productions for program structure, declarations, control flow, functions, multidimensional arrays, and expressions.
- **`ast_nodes.py`**: Strongly-typed AST node definitions implemented using Python `dataclasses` (`Program`, `FunctionDef`, `Declaration`, `IfStatement`, `ForStatement`, `WhileStatement`, `FunctionCall`, `BinaryOp`, etc.) along with a tree formatter (`format_ast`).
- **`run_parser.py`**: Independent runner for Phase 2 syntax analysis supporting AST and Symbol Table extraction.
- **`src/common/symbol_classifier.py`**: AST-walking pass that classifies every identifier into roles (`function`, `parameter`, `variable`, `array`, `typedef`, `label`), tracks scopes (`global`, `function:<name>`), and formats the Detailed Symbol Table.

---

## 2. Grammar & Features Handled

### 2.1 Operator Precedence & Associativity
Operator ambiguities and shift/reduce conflicts (such as dangling-else) are explicitly resolved in PLY via precedence declarations:

1. `right ASSIGN ADD_ASSIGN SUB_ASSIGN MUL_ASSIGN DIV_ASSIGN MOD_ASSIGN`
2. `left LOR`
3. `left LAND`
4. `left EQ NE`
5. `left LT LE GT GE`
6. `left PLUS MINUS`
7. `left STAR SLASH PERCENT`
8. `right UNARY_PLUS UNARY_MINUS NOT PRE_INC PRE_DEC`
9. `left LBRACKET RBRACKET LPAREN RPAREN`
10. `nonassoc LOWER_THAN_ELSE`
11. `nonassoc ELSE`

### 2.2 Control Flow & Function Productions
- **Conditional:** `if (expr) stmt`, `if (expr) stmt else stmt`
- **Loops:** `for (init; cond; step) stmt`, `while (expr) stmt`, `do stmt while (expr);`
- **Jumps:** `goto label;`, `break;`, `continue;`
- **Functions:** Function prototypes, definitions, argument matching, recursive calls.

## 3. Execution Commands

### Run Single File Syntax Analysis
```bash
python3 src/phase2_syntax_analysis/run_parser.py tests/phase2_syntax/valid/02_if_else.c
# or using Makefile
make parse FILE=tests/phase2_syntax/valid/02_if_else.c
```

### Run Batch Syntax Analysis
```bash
# Phase 2 test cases only
make parse-phase2

# All project test cases
make parse-all
```

### Extract AST & Symbol Table to Files
```bash
python3 src/phase2_syntax_analysis/run_parser.py tests/phase2_syntax/valid/02_if_else.c --ast-file ast.log --symbol-file symbols.log
```
